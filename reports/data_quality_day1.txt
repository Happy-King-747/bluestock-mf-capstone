3. ANOMALIES FOUND
------------------
Out of 10 core datasets, 2 anomalies were identified:

[1] 04_monthly_sip_inflows — Missing Values
    Column affected : yoy_growth_pct
    Null count      : 12 out of 48 rows (25%)
    Reason          : The first 12 months (Jan 2022 to Dec 2022) cannot
                      have a year-on-year growth value because there is
                      no prior year data to compare against. This is
                      expected behaviour and not a data error. These
                      nulls will be handled using forward-fill or left
                      as NaN during analysis.

[2] 07_scheme_performance — Negative Values in max_drawdown_pct
    Column affected : max_drawdown_pct
    Observation     : All values in this column are negative (e.g.,
                      -21.70, -24.43, -13.35).
    Reason          : This is correct and expected. Maximum drawdown
                      is always expressed as a negative percentage,
                      representing the peak-to-trough decline in a
                      fund's value. No correction is needed.

All remaining 8 datasets passed validation with zero nulls,
zero duplicates, and no unexpected values.
